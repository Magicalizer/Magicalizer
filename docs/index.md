# Magicalizer documentation

Magicalizer creates a fully featured REST API ASP.NET Core web application from your DTO, model, and entity classes:
CRUD, filtering, sorting, paging, inclusion, validation, authorization, and OpenAPI. You write the classes, not the
plumbing.

```console
dotnet add package Magicalizer
```

## Where to start

- **New to Magicalizer?** Read [What is Magicalizer](guide/introduction/what-is-magicalizer.md), then build
  [your first API](guide/getting-started/your-first-api.md) step by step.
- **Calling a Magicalizer API?** The [HTTP API](guide/http-api/endpoints.md) section describes the endpoints, filtering,
  sorting, paging, inclusion, and errors.
- **Need something special?** See [Customization](guide/customization/custom-services.md) and the
  [recipes](guide/recipes/own-data.md).
- **Looking for a type or a method?** Browse the [API reference](api/Magicalizer.Extensions.yml).
