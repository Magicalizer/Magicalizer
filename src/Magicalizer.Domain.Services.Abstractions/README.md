# Magicalizer.Domain.Services.Abstractions

`IService`, `IQueryPrefilter`, `IInclusion`, `ISorting` and the exceptions of the Magicalizer services.

It's referenced by the projects of the services and their consumers.

[Magicalizer](https://github.com/Magicalizer/Magicalizer) creates a fully featured REST API ASP.NET Core web application
from the DTO, model and entity classes, the filters and the validators. See the
[documentation](https://github.com/Magicalizer/Magicalizer#readme).
